# Changelog conventions

- Keep entries under `## Unreleased` until a release is tagged.
- Use one bullet per focused user-visible change.
- Start with a Conventional Commits type: `feat`, `fix`, `perf`, `refactor`,
  `docs`, `test`, `build`, or `chore`.
- Keep each entry to one or two lines. Do not paste implementation details.
- Move released entries under a version and date heading.
